# Piper on --piper-device cuda. piper-tts pulls in the CPU-only `onnxruntime`,
# which provides the same import name, so the two cannot be installed together:
#
#   pip uninstall -y onnxruntime
#   pip install "onnxruntime-gpu[cuda,cudnn]==1.26.0"
#
# The pin is a compute capability decision, not a preference for an older
# release. onnxruntime-gpu 1.27 and up are built against CUDA 13, which dropped
# Volta (7.0) and everything below it; on such a GPU they load and then fail in
# cuBLAS. 1.26.0 is the last CUDA 12 build. On Ampere or newer, the current
# release is fine and the pin can go.
#
# cuDNN carries the same constraint one version deeper: 9.11 dropped Volta, and
# on a 7.0 GPU the extras above resolve to a cuDNN that has no kernels for it,
# which surfaces as CUDNN_STATUS_EXECUTION_FAILED_CUDART on the first Conv.
# 9.10.2.21 is the last one that runs there:
#
#   pip install "nvidia-cudnn-cu12==9.10.2.21"
#
# Whether any of this is worth installing is a separate question, and the
# answer is not a plain yes. See the README.
